# Portfolio numérique – Alae Bousetta

**Filière :** Licence en Technologies de l'Informatique, 1re année – ISET Nabeul

## Objectif du projet
Ce site présente mes réalisations dans chaque module de 1re année : Digital Skills, développement, systèmes et développement web. Il me servira aussi pour mes candidatures de stage.

## Site en ligne
https://alaebousetta.github.io/portfolio-numerique/

## Contenu du site
- **Digital Skills** : cybersécurité, prompt engineering, création de contenu numérique
- **Développement** : Python, langage C, algorithmique
- **Systèmes** : systèmes d'exploitation, architecture des ordinateurs et électronique

## Technologies utilisées
HTML, CSS et JavaScript (checklist interactive de la page Cybersécurité). Le site est hébergé gratuitement avec GitHub Pages.

## Outils et transparence IA
J'ai utilisé Claude pour m'expliquer les étapes, corriger mon code et mon français, et m'aider à organiser les pages. J'ai aussi utilisé ChatGPT, Perplexity, NotebookLM, Canva et HeyGen. Chaque page a une fiche « Transparence IA » qui explique ce que l'IA a fait et ce que j'ai fait moi-même.
