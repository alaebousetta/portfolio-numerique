Algorithmique

Trois algorithmes sur les chaînes de caractères, avec leur idée, un exemple pas à pas et leur traduction en Python.

Algorithme 1 : compter les occurrences d'un caractère

L'idée générale

On parcourt la chaîne case par case. Chaque fois qu'on trouve le caractère cherché, on ajoute 1 au compteur.

Le pseudo-code

Algorithme Occurrence
Variables
    ch : chaîne
    c : caractère
    i, nb : entier
Début
    Écrire("Donner une chaîne : ")
    Lire(ch)
    Écrire("Donner un caractère : ")
    Lire(c)
    nb ← 0
    Pour i de 0 à long(ch) - 1 faire
        Si ch[i] = c alors
            nb ← nb + 1
        FinSi
    FinPour
    Écrire("Le caractère ", c, " apparaît ", nb, " fois")
Fin

Exemple pas à pas

Avec ch = « elle » et c = « e » :

ich[i]ch[i] = c ?nb
0eoui1
1lnon1
2lnon1
3eoui2

Résultat : le caractère « e » apparaît 2 fois.

Traduction en Python

ch = input("Donner une chaîne : ")
c = input("Donner un caractère : ")
nb = 0
for i in range(len(ch)):
    if ch[i] == c:
        nb = nb + 1
print("Le caractère", c, "apparaît", nb, "fois")

Algorithme 2 : inverser une chaîne

L'idée générale

On part de la dernière case de la chaîne et on remonte jusqu'à la première. On ajoute chaque caractère à une nouvelle chaîne, qui sera la chaîne inversée.

Le pseudo-code

Algorithme Inverse
Variables
    ch, inv : chaîne
    i : entier
Début
    Écrire("Donner une chaîne : ")
    Lire(ch)
    inv ← ""
    Pour i de long(ch) - 1 à 0 (pas -1) faire
        inv ← inv + ch[i]
    FinPour
    Écrire("La chaîne inversée est : ", inv)
Fin

Exemple pas à pas

Avec ch = « iset » (long(ch) = 4, donc i va de 3 à 0) :

ich[i]inv
3t"t"
2e"te"
1s"tes"
0i"tesi"

Résultat : la chaîne inversée est « tesi ».

Traduction en Python

ch = input("Donner une chaîne : ")
inv = ""
for i in range(len(ch) - 1, -1, -1):
    inv = inv + ch[i]
print("La chaîne inversée est :", inv)

Algorithme 3 : vérifier si un mot est un palindrome

L'idée générale

Un palindrome se lit pareil dans les deux sens, comme « radar » ou « elle ». On compare la 1re lettre avec la dernière, la 2e avec l'avant-dernière, et ainsi de suite jusqu'au milieu. Si deux lettres sont différentes, ce n'est pas un palindrome.

Le pseudo-code

Algorithme Palindrome
Variables
    ch : chaîne
    i, n : entier
    pal : booléen
Début
    Écrire("Donner un mot : ")
    Lire(ch)
    n ← long(ch)
    pal ← Vrai
    Pour i de 0 à (n div 2) - 1 faire
        Si ch[i] ≠ ch[n - 1 - i] alors
            pal ← Faux
        FinSi
    FinPour
    Si pal alors
        Écrire(ch, " est un palindrome")
    Sinon
        Écrire(ch, " n'est pas un palindrome")
    FinSi
Fin

Exemple pas à pas

Avec ch = « radar » (n = 5, n div 2 = 2, donc i va de 0 à 1) :

ich[i]n - 1 - ich[n - 1 - i]Égaux ?pal
0r4rouiVrai
1a3aouiVrai

Résultat : « radar » est un palindrome. La lettre du milieu (« d ») n'a pas besoin d'être comparée, car elle est face à elle-même.

Traduction en Python

ch = input("Donner un mot : ")
n = len(ch)
pal = True
for i in range(n // 2):
    if ch[i] != ch[n - 1 - i]:
        pal = False
if pal:
    print(ch, "est un palindrome")
else:
    print(ch, "n'est pas un palindrome")
